# Liga Web

## Integrantes
- Arnau Sánchez
- Bryan Briones

## Tema del proyecto
La Liga española de fútbol.

## Descripción
Página web informativa dedicada a la Liga española. Permite consultar información sobre algunos equipos, sus estadios y una tabla de resultados de ejemplo.

## Estructura del proyecto
- `index.html`: página principal.
- `equipos.html`: información de los equipos.
- `partidos.html`: tabla de partidos y resultados.
- `css/style.css`: estilos y diseño de la web.
- `js/script.js`: interacciones de JavaScript.

## Cómo abrir la web
1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar `index.html` en un navegador web.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Git y GitHub
